# 테이블 대화 카드

파티에서 테이블마다 폰 1대를 가운데 두고 같이 보는 대화 카드 웹앱입니다.
서버 없이 브라우저만으로 동작하고, 진행 상태는 그 폰에만 저장됩니다.

- 앱: https://snowingjerry1-droid.github.io/table-talk-cards/
- 테이블별 QR 인쇄: https://snowingjerry1-droid.github.io/table-talk-cards/qr.html
- QR 이미지 파일: `qr/` 폴더 (`table-01.png` ~ `table-09.png`, 진행자용 `main.png`)

## 구성
- 테이블 9개: 1~7번 1층, 8~9번 2층 소파
- 라운드 4개: 1라운드 첫 만남 30분, 2라운드 새 얼굴 35분, 3라운드 저녁 테이블 40분, 자유 시간(시간 제한 없음)
- 라운드마다 쓰는 카테고리가 다르고, 여러 라운드에 걸친 카테고리는 질문을 라운드별로 나눠 써서 자리를 옮겨도 같은 질문이 다시 나오지 않습니다.
- 카드 종류: 그냥 질문, 밸런스 게임(동시에 고르기), 지목(동시에 가리키기), 테이블 미션(룰렛·타이머), 우리 테이블(MIXER SEOUL 프로필로 만든 카드)
- 네 장마다 미션이나 우리 테이블 카드가 끼어 나오고, 카테고리 칩을 누르면 그 안에서만 랜덤으로 나옵니다.
- 꼬리 질문, 「이 얘기 더 하기」(자유 대화 모드), 카드 5장마다 자유 대화 안내가 있습니다.
- 우리 테이블 명단은 MIXER SEOUL(mingle_profiles)의 테이블 번호로 불러오고, 화면에서 빼거나 더할 수 있습니다.
- 주소 끝에 `?t=3`처럼 테이블 번호를 붙이면 시작 화면에서 그 번호가 미리 선택됩니다.

## 질문 고치기
`index.html` 위쪽의 `ROUNDS`(라운드)와 `CATS`(카테고리별 질문)만 수정하면 됩니다. 저장하고 GitHub에 올리면 1~2분 뒤 반영됩니다.

## 카드 배분

`ROUNDS`의 `mix`(카테고리 비율)와 `pace`(장당 분)로 라운드 시간에 맞는 장수를 정해요. 1라운드 12장, 2라운드 14장, 3라운드 13장(첫·마무리 카드 포함). 진행 중에는 설정 → 「카드 배분」에서 테이블마다 바꿀 수 있어요. `manual: true` 카테고리(연애)는 칩으로 고를 때만 나와요.
